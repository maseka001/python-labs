## 🚀 How to Run

1. Clone the repository:

   ```
   git clone https://github.com/maseka001/python-labs.git
   ```

2. Navigate into the folder:

   ```
   cd python-labs
   ```

3. Run any Python file:

   ```
   python filename.py
   ```
